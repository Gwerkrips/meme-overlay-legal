Politique de confidentialité - Meme Overlay

Dernière mise à jour : 29 mai 2026

1. Données utilisées

Meme Overlay peut lire les messages, images, GIFs ou contenus envoyés dans le salon Discord configuré afin de les afficher en overlay dans l'application.

2. Données stockées localement

L'application peut stocker localement certains paramètres sur l'ordinateur de l'utilisateur, comme les réglages d'affichage, la position de l'overlay, la taille, la durée, la langue ou les préférences locales.

3. Identifiants Discord

Le token du bot Discord et l'identifiant du salon Discord peuvent être utilisés pour connecter l'application au serveur Discord configuré. Ces informations ne doivent pas être publiées ni partagées.

4. Partage des données

Meme Overlay ne vend pas les données des utilisateurs. Les contenus Discord sont utilisés pour le fonctionnement de l'application.

5. Historique local

Certaines informations techniques ou historiques peuvent être affichées localement dans l'application afin d'aider l'utilisateur à comprendre l'état de connexion, les mises à jour ou les erreurs.

6. Suppression des données

L'utilisateur peut supprimer les données locales en désinstallant l'application ou en supprimant les fichiers de configuration locaux associés à Meme Overlay.

7. Contact

Pour toute question concernant la confidentialité, contacte le développeur ou l'administrateur qui t'a fourni l'application.
